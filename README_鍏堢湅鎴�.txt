自动点击助手（Android 原生源码）

这份工程是通用的、由用户明确配置坐标的无障碍点击器，不是针对《三角洲行动》已经适配好的自动收菜机器人，也不是 APK 安装包。

当前功能：
- 用户填写屏幕像素 X/Y 坐标；
- 设置点击间隔（至少 1000ms）和点击次数（最多 30 次）；
- 开启 Android 无障碍服务后执行；
- 可随时停止；
- 点击完成或系统取消时自动停止。

重要限制：
- 尚未实现游戏画面识别、四个生产位的自动导航、物品识别、哈夫币弹窗识别或 8 小时定时启动。
- 由于不同手机分辨率、游戏 UI 缩放和页面状态会改变坐标，不能把猜测坐标写死；必须由使用者在目标设备上校准。
- 哈夫币属于游戏内消耗，务必在每次确认前人工核对；本工具不会自动确认付费/消耗弹窗。
- 不读取游戏内存、隐藏信息或尝试规避反作弊。

构建：
需要 Android Studio 和 Android SDK（compileSdk 35）。在项目目录执行：
  gradle assembleDebug
输出位置：app/build/outputs/apk/debug/app-debug.apk

Acode 可编辑文件，但不能代替 Android SDK/Gradle 编译。此工程未经真实设备构建与测试，请先在无风险页面验证。
