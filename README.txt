三角洲收菜助手 - Android 项目基础包

编译：
1. 将整个 DeltaTapHelper 文件夹上传到一个新的 GitHub 仓库。
2. 确认 .github/workflows/build-apk.yml 一并上传。
3. 打开仓库 Actions，运行 Build Android APK。
4. 成功后在运行记录的 Artifacts 下载 DeltaTapHelper-debug-apk。

重要说明：
这是可编译的 Android 无障碍服务项目骨架，不是已经完成四站自动点击的成品。
游戏按钮坐标、页面切换方式尚未校准。未校准前不会自动点击，也不会消耗哈夫币。
Android 12 需由用户在系统无障碍设置中手动开启服务。
